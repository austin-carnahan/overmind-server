# Kodi client

Status: client plan; a local GUI/RetroPie installation on overmind-01 is not assumed.

Configure access to the canonical movie and TV collections under
`/mnt/library/movies` and `/mnt/library/tv` through the chosen share/server.
The client uses its network paths; the server path is not automatically local on
another device. Never index inbox or quarantine directories.

Retain movie folders such as `Movie Name (Year)/Movie Name (Year).mkv` and TV
folders such as `Show Name (Year)/Season 01/Show Name - S01E01.ext` when supported
by the selected organizer. Verify library discovery, subtitles, and playback.
Keep unique client metadata recoverable where desired.
