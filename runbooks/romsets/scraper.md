After ROM paths and canonical names are stable (Igir's DAT/1G1R output):
RetroArch's own built-in thumbnail downloader matches games by standard
No-Intro/Redump filenames against an official server — no separate scraper
tool needed for the bulk of standard-cataloged titles, verified as a current
(1.17.0+) RetroArch feature. Keep presentation rebuildable from canonical ROM
filenames; only reach for a dedicated scraper if a specific title genuinely
isn't covered by RetroArch's own thumbnail matching.
