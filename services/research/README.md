# Research tools

Status: capability plan; application selection and deployment are pending.

Substrate owns shared notes, papers, and datasets. Projects own project-specific
analysis, working notes, data, and outputs. A shared Obsidian vault is proposed
for `/mnt/substrate/notes`; project notes do not need a duplicate vault copy.

Select citation/attachment ownership and note synchronization before importing a
large corpus. Define conflict handling and preserve portable annotations where
supported. Synchronization is separate from backup; do not sync live databases
as ordinary files.

Future search/indexing is a consumer of that material. Its database/vector store
and caches use supported service paths outside Substrate, optionally SSD-backed.
An index is disposable only if all valuable contents can be reproduced. Preserve
manual metadata/annotations even if an application stores them in its database.

First useful workflow: capture one paper, create a note or project reference,
retrieve it from a client, and demonstrate recovery. Search services can wait.
