# File sharing

Status: planned. Samba is retained as a candidate for media clients; no share
configuration, users/groups, or daemon has been provisioned.

Share only intended Substrate or Library collections. Prefer read access for playback,
route incoming contributions through typed Inbox paths, and retain scoped project
write permissions. Archive maintenance/import access is granted separately. Do not
export service-private databases or grant access to the entire SSD.

Before deployment, choose protocols per client, authentication, native service
state paths, required mounts, private networking, and verification. Confirm both
permitted access and denied writes. Keep remote administration private and
preserve a rollback/export procedure. See [client plans](../../runbooks/README.md).
