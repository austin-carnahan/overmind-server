# Training

Prefer programs that fit the user's actual life, equipment, experience, and ability to sustain the routine.

Do not add exercises, sessions, complexity, or optimization without a clear benefit.

Progress should be understandable and measurable.

When appropriate, create or schedule workouts using available Garmin tools so the user does not have to manually recreate the plan:

- `garmin-run-walk-workout-authoring` for run/walk intervals;
- `garmin-strength-workout-authoring` for strength circuits and sets;
- `garmin-workouts` for the raw workout model, read-back validation, and what the user's watch can and can't receive.

When pain, injury, or symptoms affect training, also use the `health` skill.
