# Garmin one-off food logging

1. First check for a plausibly matching canonical local recipe when the dish sounds recurring; use `garmin-recipe-authoring` instead if found. For a one-off composite meal, identify ingredient portions and search Garmin foods for branded products and common ingredients. Prefer package details supplied by the user over a generic match; estimate missing amounts and state the consequential assumptions.
2. Log matching catalog foods with `log_custom_food`, passing the `food_id`, `serving_id`, and `source` returned by `search_foods` (commonly `FATSECRET`). This retains available fiber, sodium, and other nutrients without creating a recipe or cluttering the custom-food library. When decomposition is impractical but a single full-nutrient estimate is useful, a Garmin custom food can hold fiber/sodium; distinguish that derived logging entry from a canonical local recipe. Set the intended nutrient fields before logging: editing a custom food later does not update an existing log entry’s nutrient snapshot. `log_food` Quick Add stores only calories and macros, so do not choose it silently when fiber or sodium matters.
3. Before writing, check the date/meal for duplicates. After writing, read `get_nutrition_daily_food_log` and confirm item names, quantities, meal placement, and available nutrient totals. For an ingredient-level composite, multiply each entry’s per-serving `nutritionContent` by `servingQty` before summing; if the meal already contained other foods, report the new composite separately from the full meal total. Do not present estimated sodium or fiber as measured; catalog matches may be approximate or omit fields.
4. To repair an incomplete Quick Add or a stale custom-food snapshot, log the complete replacement and verify its fields first, then delete only the old entry using its exact `logId` and date via `delete_food_log`. Read back again to confirm exactly one intended entry remains and the meal totals include its nutrients. If some source fields remain unknown, report that limitation.
